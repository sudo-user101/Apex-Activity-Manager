# Contributing to Apex

Thanks for wanting to help. Apex is source-available under the
[PolyForm Strict License 1.0.0](LICENSE): you can read it, build it and use
it for noncommercial purposes, but the license doesn't allow changes or new
works based on it. So the best ways to help aren't code, and they matter a
lot.

## Ways to help

- **Report bugs.** Use the [bug report form](https://github.com/sudo-user101/Apex-Activity-Manager/issues/new?template=bug_report.yml):
  your Apex and macOS versions, your Mac model, and the steps to make it
  happen. A screenshot (with anything personal hidden) helps most.
- **Suggest features.** Use the [feature request form](https://github.com/sudo-user101/Apex-Activity-Manager/issues/new?template=feature_request.yml)
  and start from the problem you have ("my Mac gets slow every afternoon
  and I can't tell why") rather than a solution. Problems lead to better
  features.
- **Check a number.** If Apex shows a value that disagrees with macOS or
  another tool, say where you saw both. [Where each number comes from](docs/DATA-SOURCES.md)
  explains how Apex reads it.
- **Test on your hardware.** Some features depend on the Mac: fans (every
  Mac except MacBook Air with Apple silicon), batteries, external displays, USB hubs and docks. Reports
  of what works, and what doesn't, on your model are very useful.
- **Report security problems privately**, as described in the
  [security policy](SECURITY.md), not as public issues.

Before opening an issue, search the [open issues](https://github.com/sudo-user101/Apex-Activity-Manager/issues):
adding your details to an existing one is better than a duplicate.

## Pull requests

Pull requests with code aren't accepted: the license doesn't allow changes
to the software, and Apex is designed and built by one person. If you've
found a fix, describe it in an issue instead (what's wrong, and where in the
source), and it will be credited when it lands.

Typo fixes in the documentation are welcome as issues too.

## Suggestions and ideas

Ideas you share in issues may be used in Apex. Please only share ideas you're
happy to give, and don't paste code or text you don't have the right to share.

## Building it yourself

You're welcome to build Apex from source for your own use (see
[Build from source](README.md#build-from-source)). Please don't publish
builds or copies; point people to the
[releases page](https://github.com/sudo-user101/Apex-Activity-Manager/releases/latest)
instead.

## Be kind

Be respectful and constructive. Issues are for Apex; anything abusive or off
topic will be closed.
